# Toolyfi

Toolyfi is a collection of practical browser-based tools for everyday work, including calculators, text utilities, developer helpers, and simple generators.

## Featured tools

- [Loan Calculator](https://toolyfi.com/loan-calculator.html) — estimate monthly payments and total interest.
- [QR Code Generator](https://toolyfi.com/qr-code-generator.html) — create QR codes directly in the browser.
- [Password Generator](https://toolyfi.com/password-generator.html) — generate strong random passwords locally.
- [Unit Converter](https://toolyfi.com/unit-converter.html) — convert common measurements quickly.
- [Markdown to HTML Converter](https://toolyfi.com/markdown-to-html-seo.html) — convert Markdown into clean HTML.
- [Word Counter](https://toolyfi.com/word-counter.html) — count words, characters, and reading time.
- [BMI Calculator](https://toolyfi.com/bmi-calculator.html) — calculate BMI using height and weight.
- [Age Calculator](https://toolyfi.com/age-calculator.html) — calculate age from a birth date.

Visit [Toolyfi](https://toolyfi.com/) to browse the complete collection.

## Development

This repository contains the static site source and browser-based utility pages. Contributions and issue reports are welcome when they improve usability, accessibility, correctness, or performance.
