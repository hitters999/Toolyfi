DEG vs RAD vs GRAD — Angle Modes Explained

DEG (Degree) Mode

In DEG mode, angles are measured in degrees. One full revolution = 360°. This is the most common mode for school-level mathematics, physics problems, and everyday trigonometry in Pakistan's FSc and O-level curriculum. Use DEG for any problem where angles are given as 30°, 45°, 60°, 90°, etc.

Key values in DEG: sin(30°) = 0.5, cos(60°) = 0.5, tan(45°) = 1, sin(90°) = 1.

RAD (Radian) Mode

In RAD mode, angles are measured in radians. One full revolution = 2π radians ≈ 6.2832. Use RAD for calculus problems, wave motion, circular motion in physics, and any formula that uses π explicitly in the angle (e.g., sin(π/6), cos(π/3)).

Key values in RAD: sin(π/6) = 0.5, cos(π/3) = 0.5, tan(π/4) = 1, sin(π/2) = 1.

Common Mistakes and How to Avoid Them

  • Wrong angle mode: The #1 source of wrong answers. Always check DEG/RAD badge before any trig calculation. Switching mode mid-calculation invalidates all previous trig results.
  • Forgetting SHIFT: Pressing sin without SHIFT computes sin. Pressing sin after SHIFT computes sin⁻¹. The S indicator must be visible for SHIFT functions to activate.
  • Order of operations: Use parentheses to enforce correct calculation order. 2+3×4 = 14 (not 20). The calculator follows BODMAS/PEMDAS automatically when parentheses are used correctly.
  • tan(90°) error: tan(90°) is mathematically undefined. The calculator returns a Math Error for this input, which is correct behavior.
  • Log of zero or negative: log(0) and ln(0) are undefined (negative infinity). log of a negative number is undefined in real numbers. The calculator returns Math Error for these inputs.
  • Square root of negative: √ of a negative number is imaginary. The calculator returns Math Error. Check your input value.
