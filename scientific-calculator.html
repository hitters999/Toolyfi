DEG vs RAD — When to Use Each

This is the most important setting to understand before using any scientific calculator. Using the wrong mode produces completely wrong answers in trigonometric calculations.

DEG (Degree) Mode

In DEG mode, one full revolution = 360 degrees. Use DEG mode for: school trigonometry problems, geometry, surveying, navigation, and any problem that gives angles in degrees (30°, 45°, 90°, etc.).

sin(30°) = 0.5, cos(60°) = 0.5, tan(45°) = 1

RAD (Radian) Mode

In RAD mode, one full revolution = 2π radians (≈ 6.2832). Use RAD mode for: calculus, physics (especially wave and circular motion problems), and any formula that uses π in the angle (e.g., sin(π/6), cos(π/3)).

sin(π/2) = 1, cos(π) = -1, tan(π/4) = 1

Common Calculation Mistakes and How to Avoid Them

  • Wrong angle mode: Always check DEG/RAD before trig calculations. This is the #1 source of errors.
  • Forgetting SHIFT: For inverse trig and second functions, press SHIFT first. The S indicator must be visible in the display.
  • Order of operations: Use parentheses ( ) to enforce the correct calculation order in complex expressions.
  • Square root of negatives: √ of a negative number gives Math Error. Check your input value first.
  • tan(90°) error: tan(90°) is undefined (division by zero). The calculator shows Math Error for this input.
