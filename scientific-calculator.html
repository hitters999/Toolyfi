DEG vs RAD — When to Use Each

DEG (Degree) Mode

In DEG mode, one full revolution = 360 degrees. Use DEG mode for school trigonometry problems, geometry, surveying, and navigation.

sin(30°) = 0.5, cos(60°) = 0.5, tan(45°) = 1

RAD (Radian) Mode

In RAD mode, one full revolution = 2π radians. Use RAD mode for calculus, physics, and any formula that uses π in the angle.

sin(π/2) = 1, cos(π) = −1, tan(π/4) = 1

Common Calculation Mistakes and How to Avoid Them

  • Wrong angle mode: Always check DEG/RAD before trig calculations. This is the #1 source of errors.
  • Forgetting SHIFT: For inverse trig and second functions, press SHIFT first. The S indicator must be visible.
  • Order of operations: Use parentheses ( ) to enforce the correct calculation order in complex expressions.
  • Square root of negatives: √ of a negative number gives Math Error. Check your input value first.
  • tan(90°) error: tan(90°) is undefined. The calculator shows Math Error for this input.
