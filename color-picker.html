Color Code Formats Explained

  • HEX — Used in CSS and web design (e.g. #ff3cac)
  • RGB — Red, Green, Blue values from 0 to 255 (e.g. 255, 60, 172)
  • HSL — Hue, Saturation, Lightness — great for adjusting and theming colors

Frequently Asked Questions

What is a HEX color code?

A HEX color code is a 6-digit code used in CSS and web design to represent colors, starting with a # symbol. For example, #ff3cac represents a bright pink color.

What is the difference between RGB and HSL?

RGB defines colors using Red, Green, and Blue values (0–255 each). HSL uses Hue, Saturation, and Lightness, which is more intuitive for tweaking colors visually. Both are widely supported in CSS.
